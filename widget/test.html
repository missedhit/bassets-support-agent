This is a test page for the support chat widget. Look for the chat bubble in the bottom-right corner.

Testing the widget

1. Make sure the server is running: python server.py

2. Click the chat bubble in the bottom-right corner

3. Ask a question about depreciation, asset management, or Bassets software

Embedding on your real site

Add this one line before </body> on any page of bassets.net:

<script src="https://your-server.com/widget.js" data-api="https://your-server.com"></script>
